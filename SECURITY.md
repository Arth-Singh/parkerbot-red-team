# Security and disclosure

This repository documents an already reported assessment at a deliberately
non-operational level.

Do not place any of the following in an issue, pull request, commit, or fork:

- live endpoints or tenant identifiers;
- session, conversation, or authentication material;
- raw HAR files or replayable requests;
- harmful test prompts or verbatim model responses;
- private disclosure correspondence; or
- employer, client, or vendor source code.

Report NASA-scope vulnerabilities through NASA's current Vulnerability
Disclosure Policy channel. Report repository mistakes privately to its owner.
