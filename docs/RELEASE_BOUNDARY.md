# Responsible release boundary

## Included

- High-level scope, method, findings, and mitigations.
- Rounded engagement-scale measurements.
- NASA VDP Letter of Recognition supplied to Arth Singh.
- SHA-256 digest for the public recognition letter.
- Independently written offline aggregation code.
- Synthetic records and benign probe examples.

## Withheld

- Production endpoint and vendor-specific protocol details.
- Live collection, tenant, session, and conversation identifiers.
- Browser captures, request headers, cookies, and replay bodies.
- Raw prompts, model responses, and retrieved documents.
- Finding-specific success rates and reproduction steps.
- Private report, disclosure correspondence, and customer data.
- Original assessment/reconnaissance framework and its Git history.

## Public-release gate

Before changing repository visibility to public:

1. Obtain written publication approval from any employer/client with a plausible
   ownership or confidentiality interest.
2. Confirm disclosure terms permit the remaining technical detail.
3. Re-run secret, identifier, document-metadata, and Git-history checks.
4. Re-read every claim for exact target attribution.
5. Publish from this clean repository only; never merge the private framework's
   history.

Private reviewer access does not override ownership or confidentiality terms.
